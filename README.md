## 🚀 Quick Start

### Prerequisites
- Node.js 18+ installed

### Installation
\`\`\`bash
npm install
\`\`\`

### Development
\`\`\`bash
npm run dev
\`\`\`

### Build
\`\`\`bash
npm run build
\`\`\`

### Start Production
\`\`\`bash
npm start
\`\`\`
